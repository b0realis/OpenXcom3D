OpenXcom3D for Windows (64-bit, Windows 10 and 11)

OpenXcom Extended with a first-person 3D battlescape. It needs the original game's data:
X-COM: UFO Defense (UFO: Enemy Unknown) and/or X-COM: Terror From The Deep.

Starting
  Double-click play.bat. The first time, it looks for the games in your Steam library and
  links them in (it changes nothing there). Without Steam, copy the game's folder (the one
  with GEODATA, GEOGRAPH, MAPS and UFOGRAPH in it) into the user folder here and name it UFO
  (or TFTD), or put it next to play.bat.

  Keep this folder somewhere of yours (Documents, the Desktop, C:\Games): the game writes its
  saves and options into its user folder, and can't in Program Files.

  Windows may warn the first time ("Windows protected your PC"), since the game isn't signed:
  click "More info", then "Run anyway".

In battle press F8 (or click the 3D button at the top left) for the first-person view. Every
key and setting is in OpenXcom3D_manual.md (a text file: any editor or browser shows it).

Your saves, the options and the log (openxcom.log) are in the user folder.
Source, news and the Linux version: https://github.com/b0realis/OpenXcom3D
